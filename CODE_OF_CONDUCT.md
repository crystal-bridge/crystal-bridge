# Code of conduct

Crystal Bridge follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good intent, keep criticism about the work, and don't harass anyone, in issues, pull
requests, discussions or anywhere else the project lives.

**Reporting.** If someone's behaviour worries you, tell the maintainers privately through GitHub: open a private
security advisory on the repository ("Report a vulnerability") and say it is a conduct report. Reports are kept
confidential. Maintainers may remove comments, lock threads, or block people who don't follow this code.
