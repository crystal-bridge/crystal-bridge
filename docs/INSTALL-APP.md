# Install the app

Crystal Bridge is a web app that you can install, so it gets its own icon and window, with no browser bars around it.
Nothing is downloaded separately: the installed app loads from your hub, and it updates whenever the hub does.

Browsers only offer to install a site served over HTTPS, or from `localhost`. A hub set up as in
[Several machines](./SEVERAL-MACHINES.md) has HTTPS already.

## Install it

Open your hub's address in the browser, then:

- **Chrome or Edge on a computer:** select the install icon at the end of the address bar, or find **Install** in the
  browser's menu.
- **Safari on a Mac:** choose **File > Add to Dock**.
- **Android:** in Chrome's menu, select **Add to Home screen** or **Install app**.
- **iPhone or iPad:** in Safari, select **Share**, then **Add to Home Screen**.

## Notifications on a phone

Turn on **Push to this device** in the app to get notifications when the app is closed. On an iPhone or iPad, install
the app first: Safari only offers Web Push to an app on the Home Screen. Hub operators can find the details under
[Web Push](./OPERATIONS.md#web-push).

## Moving your hub

An installed app belongs to its address. Keep the hub's address when you move it, and the installed app, its settings
on that device and its push subscription keep working. At a new address, install the app again.
